# 요괴 자판기 | Yokai Vending Machine

작은 창에서 요괴를 관찰하고 촬영해 도감과 물건함에 모으는 웹 게임입니다.

- 서비스: https://www.yokaivendingmachine.com/
- 공개 범위: 프런트엔드·서버 로직, 재사용 가능한 인프라 정의, 관련 테스트 코드
- 기술: React, TypeScript, Vite, AWS Lambda, DynamoDB, S3, CloudFront

## 직접 판단한 일과 AI 활용

콘셉트와 기능 요구사항, 화면 구성, 개선 우선순위를 정하고 결과를 검토했습니다. 코드 작성·문제 분석·수정·테스트·배포에는 Codex를 활용했습니다. AI가 작성한 코드 전체를 독립적으로 작성한 역량으로 주장하지 않습니다.

배포 후 사용자에게 받은 글자 크기 등 사용성 피드백을 수정 요구사항으로 바꾸고 결과를 확인했습니다.

## 코드 읽기

- `src/runtime/`: 브라우저의 등장 후보·대기 시간 계산과 방문 실행
- `src/domain/`, `src/storage/`: 상태·저장 계약과 사진 보관
- `src/account/`: 계정 연결과 서버 동기화
- `server/`: API·저장 어댑터·백업 로직
- `infra/template.mjs`: Lambda·DynamoDB·S3·CloudFront 구성 정의
- `scripts/*.test.mjs`: 해당 기능의 테스트 코드

랜덤 등장·대기는 브라우저에서 처리합니다. 서버 계정 모드에서는 방문 시작·수집·종료·상태 동기화에도 서버와 통신합니다. 실제 운영 비용 절감액이나 절감률은 측정하지 않았습니다.

## 공개용 사본의 제한

이 저장소는 코드 검토용 소스 스냅샷입니다. 이미지·모델·텍스처·음원·폰트·빌드, 원본 제작 자료, 내부 보고서, 실제 사용자 데이터, 운영 설정·계정 정보와 기존 Git 이력은 포함하지 않습니다. 리소스 경로와 콘텐츠 목록은 코드 구조를 설명하기 위해 일부 남아 있습니다.

따라서 이 저장소만으로 출시 버전을 그대로 실행하거나 전체 테스트·빌드를 재현할 수는 없습니다. 리소스 의존 검사와 실행 명령은 원본 개발 환경을 기준으로 합니다. 운영 서비스를 수정하거나 배포하는 작업은 수행하지 않습니다.

코드와 콘텐츠의 재배포·상업적 이용 허가는 별도로 부여하지 않습니다.
